🎮 Jogoteca

Um projeto que reúne vários jogos em um só lugar, criando uma pequena plataforma de entretenimento com diferentes opções para jogar.

📌 Sobre o projeto

A Jogoteca foi desenvolvida para reunir diferentes jogos em uma única aplicação. O usuário pode acessar o menu principal, escolher um jogo e começar a jogar de forma simples e intuitiva.

O projeto também serve como uma forma de praticar lógica de programação e criação de jogos.

🕹️ Jogos disponíveis

Atualmente, o projeto conta com diferentes jogos, como:
Impar e par.
Calculadora.
Jokenpo
Mad Libs.

Novos jogos podem ser adicionados ao projeto futuramente!

🎯 Objetivo

O principal objetivo do projeto é criar uma central de jogos simples e divertida, enquanto são praticados conceitos importantes de programação, como:

Lógica de programação;
Animações;
Sistemas de pontuação;
